# ObsidianKeep (Android)

Мобильные заметки в стиле Obsidian × Google Keep — готовый Gradle-проект
для актуальной Android Studio (AGP 9.4.1, Gradle 9.8.1, встроенный Kotlin).
Один плоский пакет `com.example.obsidiankeep`, UI целиком в коде,
без XML-лейаутов; векторные иконки — в `res/drawable`, русские строковые
литералы и KDoc. Визуальный язык повторяет веб-live-view: тёмная тема
по умолчанию, нейтральный цинк + фиолетовый акцент, карточки с цветной
подложкой, чипы и bottom-sheet выборы.

## Возможности

- Markdown-заметки: заголовки, списки/чекбоксы, `код`, **жирный**, [[вики-ссылки]], #теги
- Режимы «Правка / Чтение» с live-предпросмотром (markdown → Spannable)
- Бэклинки «Ссылки сюда»; переход по [[вики-ссылке]] открывает/создаёт заметку
- 8 цветов карточек, **насыщенная подложка по умолчанию** (цвета менее прозрачные)
- Избранное, закрепление, папки со счётчиками
- **Защита папок**: PIN (PBKDF2) и/или биометрия, содержимое заметок зашифровано
  AES/GCM ключом из Android Keystore, скрытие заметок заблокированных папок
  из всех списков, авто-блокировка при сворачивании, пауза против перебора
- Поиск по заметкам: заметное поле-пилюля с иконкой и кнопкой очистки,
  живой фильтр с дебаунсом 220 мс + сортировка через bottom-sheet
  (Недавние / Новые / По алфавиту / По напоминанию) и свотчи цветов;
  фильтры по тегу и цвету с чипами сброса
- Переключатель светлой/тёмной темы в верхней панели (солнце/луна)
  плюс полный выбор темы в настройках
- **Календарь напоминаний в 4 режимах** — Неделя / Месяц / Год / День:
  счётчики и точки, кнопка «Сегодня», навигация по периоду, панель дня
  с созданием напоминания и действиями; уведомления через AlarmManager
- Граф связей на canvas (force-симуляция, перетаскивание, тап → заметка,
  статистика «узлы · связи»)
- Корзина с хранением 10 дней, восстановлением, автоочисткой и undo-снекбаром
- Облако тегов с масштабом по счётчику
- Настройки (в шторке сразу после «Теги»): тема Системная/Светлая/Тёмная,
  цвет подложки Насыщенная/Приглушённая, сетка Обычная/Компактная
- Edge-to-edge для современных Android 15+ устройств (отступы панелей,
  клавиатура не перекрывает редактор), иконка приложения в res/mipmap

## Быстрый старт

1. Android Studio → File → Open → папка проекта → дождаться синхронизации → Run ▶
   или в терминале: `./gradlew assembleDebug`
2. Подробности (требования, версии, структура, траблшутинг) — в `SETUP.md`.

## Формат данных

Автономное хранилище: `filesDir/obsidiankeep/notes.json` и `folders.json`
(атомарная асинхронная запись). Теги выводятся из текста (#хэштеги),
отдельной таблицы нет. Заметки защищённых папок лежат шифротекстом
AES/GCM (ключ — в Android Keystore), при порче JSON делается *.corrupt-копия.

## Сборка (проверено)

Gradle 9.8.1 + AGP 9.4.1, JDK 21, compileSdk 37, targetSdk 35, minSdk 23:
`./gradlew assembleDebug` → **BUILD SUCCESSFUL** → установочный APK
(`app/build/outputs/apk/debug/app-debug.apk`, пакет `com.example.obsidiankeep`).
